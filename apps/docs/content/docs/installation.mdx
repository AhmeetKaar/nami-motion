---
title: Installation
description: Add nami-motion to an Expo or React Native project.
---

```bash
npx expo install nami-motion react-native-reanimated react-native-worklets react-native-gesture-handler
```

Components that draw with Skia live in `nami-motion/skia`, and the gradient
shimmer lives in `nami-motion/gradient`. Their native dependencies are only
needed if you import them:

```bash
npx expo install @shopify/react-native-skia expo-linear-gradient
```

Import from the entry point you need to keep bundles small:

```tsx
import { ShimmerText } from 'nami-motion/text';
import { VoiceWave } from 'nami-motion/skia';
```
