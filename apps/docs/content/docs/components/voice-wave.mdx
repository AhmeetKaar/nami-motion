---
title: Voice Wave
description: Three-layer Skia waveform driven by live microphone level.
---

## Installation

```bash
bunx expo install nami-motion react-native-reanimated react-native-worklets @shopify/react-native-skia
```

## Usage

```tsx
import { VoiceWave } from 'nami-motion/skia';

const level = useSharedValue(0);

<VoiceWave level={level} colors={["#7C5CFF", "#4CC9F0", "#F72585"]} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `level` | `SharedValue<number>` | — | Normalized input level 0-1 |
| `colors` | `[string, string, string]` | — | One color per wave layer |
