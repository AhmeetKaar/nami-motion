---
title: Remaining Ring
description: Animated progress ring for quotas, timers and recording limits.
---

## Installation

```bash
bunx expo install nami-motion react-native-reanimated react-native-worklets @shopify/react-native-skia
```

## Usage

```tsx
import { RemainingRing } from 'nami-motion/skia';

<RemainingRing size={28} progress={0.4} trackColor="#333" color="#FFF" />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `number` | — | Diameter |
| `progress` | `number` | — | 0-1 |
| `trackColor` | `string` | — | Track color |
| `color` | `string` | — | Progress color |
| `strokeWidth` | `number` | — | Stroke width |
| `duration` | `number` | — | Transition in ms |
| `children` | `ReactNode` | — | Centered content |

Reduce Motion is respected: the animation settles into its static state.
