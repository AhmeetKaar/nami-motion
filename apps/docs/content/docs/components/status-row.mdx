---
title: Status Row
description: Pulsing loading state with your logo and a status label.
---

## Installation

```bash
npx expo install nami-motion react-native-reanimated react-native-worklets
```

## Usage

```tsx
import { StatusRow } from 'nami-motion/chat';

<StatusRow label="Searching the web" color="#A1A1A1" icon={<Logo />} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Status text |
| `color` | `string` | — | Label color |
| `icon` | `ReactNode` | — | Leading logo or icon |
| `iconSize` | `number` | — | Icon box size |
| `labelStyle` | `StyleProp<TextStyle>` | — | Typography |
| `duration` | `number` | — | Pulse duration in ms |

Reduce Motion is respected: the animation settles into its static state.
